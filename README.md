# Al Aidy Group | Business, Banking & Finance Support UAE

Exported from Framer by [Full Site Export](https://getfull.site).

```bash
npm install
npm run dev
```

## Layout

- `app/_components/` — your components, CSS modules and design tokens
- `app/page.tsx` and `app/<route>/page.tsx` — one route per exported page
- `theme.css`, `tokens.module.css` — variables read from your Framer project

## Notes

- Images still point at Framer's CDN. Re-export with asset localisation,
  or replace the URLs, before relying on this offline.
- `_dump.json` is the raw project tree; the exporter can re-run from it
  without another export from Framer.
